# WhatYourPronouns

Displays players' pronouns, fetched from [PronounDB](https://pronoundb.org/) using their Minecraft UUID, next to their name:

- in chat
- above their head
- in the player tab list
- in the social interactions screen
- in [Enhanced Player List](https://modrinth.com/mod/enhanced-player-list)'s panel, when it's installed (NeoForge)

Lookups are cached and resolved asynchronously, so gameplay is never blocked waiting on a network call.

## Supported versions

| Minecraft | Loader   |
|-----------|----------|
| 1.20.1    | Fabric   |
| 1.21.1    | Fabric   |
| 1.21.1    | NeoForge |

## Installation

Download the build matching your Minecraft version and loader from [Modrinth](https://modrinth.com/mod/whatyourpronouns) or the [Releases](https://github.com/enimaloc/whatyourpronouns/releases) page.
